# 成绩核算系统 v2.0.2

成绩核算 Web 应用。上传登分表 Excel，自动计算班级排名、教师评比，导出标准报表。

## 更新日志

### v2.0.2（2026-05-11）

- **新增**：教师任课 Excel 导入支持自动按班级名识别年级并归类——导入包含七/八/九年级混合数据时，系统自动识别班级名中的年级关键词（"七""八""九"），将教师拆分到对应年级。跨年级教师（如同时带七年级和八年级的课）自动拆分为多条记录。
- **改进**：教师导入由覆盖模式改为合并模式——自动归类时不会冲掉已有配置，仅新增不重复的记录。
- **新增**：导入弹窗增加"自动按班级识别年级并归类"开关（默认开启），可关闭以保持原有行为。

### v2.0.1（2026-05-11）

- **修复**：激活码验证异常处理——当 `check_activation()` 抛出异常时，原逻辑会静默放行，导致未激活用户可正常使用。现改为异常时拒绝访问并跳转激活页面。
- **修复**：试用时间解析的时区兼容性——当存储的 ISO 时间字符串带时区信息时，与 `datetime.now()` 相减会报 `TypeError`，导致激活页面无法打开。

### v2.0.0（2026-05）

- 初始发布版本
- 上传 Excel → 自动识别年级/科目 → 计算排名 → 导出四张标准报表
- 激活码系统（机器绑定 + HMAC-SHA256 离线验证）
- 3 天免费试用
- Inno Setup 安装程序

## 快速开始

### 方式一：安装程序（推荐）

双击 `成绩核算系统_v2.0.2_安装包.exe`，按向导安装。自动创建桌面快捷方式。

### 方式二：直接运行

双击 `成绩核算系统.exe`，浏览器自动打开。无需安装 Python。

### 方式三：源码运行

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000

### 3. 使用流程

**首次使用：**
1. 上传登分表 Excel → 系统自动检测年级和科目
2. 进入确认页核对科目、应考人数、教师任课
3. 勾选"保存配置"后提交 → 查看结果 → 下载报表

**后续使用：**
- 直接点"开始计算"，上传文件即出结果（自动使用已保存配置）

## 导出报表（4 张 Sheet）

1. **登分表** — 每生各科成绩 + 单科班名/级名 + 总分班次/级次
2. **考试结构成绩表** — 班级综合排名（结构总分）
3. **人均及及格率** — 各班各科统计 + 学科排名
4. **任课教师成绩评比表** — 教师考核分排名

## 算法概要

- **及格** = 成绩 ≥ 满分 × 60%（可调）
- **优秀** = 成绩 ≥ 满分 × 80%（可调）
- **班级结构总分** = 人均得分 + 合格率得分 + 优秀率得分 + 进线率得分 + 参考率得分 + 前N名得分 + 增值评价
- **教师考核分** = 平均分得分 + 及格率得分 + 优秀率得分

详细公式见系统内"算法参数"页面的"算法说明"。

## 激活码系统

系统采用「机器绑定 + 激活码」保护机制：
- 每台电脑有唯一的**机器码**（基于硬件信息生成）
- 管理员根据机器码生成对应的**激活码**
- 支持两种激活码：**永久激活码**（V1 开头）和**试用激活码**（T1 开头，3天有效期）
- 首次运行自动进入 3 天试用期，无需激活码

### 管理员工具

打包管理员工具：

```bash
python -m PyInstaller admin_genkey.spec --noconfirm
```

生成激活码：

```bash
# 生成永久激活码
激活码生成工具.exe <学校代码> <机器码>

# 生成试用激活码（3天）
激活码生成工具.exe --trial <学校代码> <机器码>
```

详细说明见 `激活码使用说明.md`。

## 注意事项

- `config/` 目录存放教师任课等配置，请勿删除
- `uploads/` 为临时目录，可随时清空
- 修改算法参数后会影响所有年级的计算结果
- Excel 表头中"班级"列之后、"总分"列之前的所有列会被识别为科目
