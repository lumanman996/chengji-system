# 成绩核算系统 v2

成绩核算 Web 应用。上传登分表 Excel，自动计算班级排名、教师评比，导出标准报表。

## 快速开始

### 方式一：直接运行（推荐）

双击 `成绩核算系统.exe`，浏览器自动打开。无需安装 Python。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000

### 3. 使用流程

**首次使用：**
1. 上传登分表 Excel → 系统自动检测年级和科目
2. 进入确认页核对科目、应考人数、教师任课
3. 勾选"保存配置"后提交 → 查看结果 → 下载报表

**后续使用：**
- 直接点"开始计算"，上传文件即出结果（自动使用已保存配置）

## 打包为 exe

运行 `打包.bat` 或：

```bash
python -m PyInstaller chengji.spec --noconfirm
```

输出在 `dist\成绩核算系统\` 目录，整个文件夹复制到目标电脑即可使用。

## 功能说明

| 功能 | 说明 |
|------|------|
| 自动检测 | 从 Excel 表头自动识别年级、科目、班级 |
| 科目灵活 | 不限于预设科目，Excel 里有几科就算几科 |
| 教师导入 | 支持 Excel 批量导入教师任课信息 |
| 算法可调 | 所有权重、比例、系数均可在"算法参数"页面配置 |
| 配置记忆 | 教师任课、应考人数保存后长期复用 |
| 模板下载 | 按年级下载空白登分表模板 |

## 导出报表（4 张 Sheet）

1. **登分表** — 每生各科成绩 + 单科班名/级名 + 总分班次/级次
2. **考试结构成绩表** — 班级综合排名（结构总分）
3. **人均及及格率** — 各班各科统计 + 学科排名
4. **任课教师成绩评比表** — 教师考核分排名

## 算法概要

- **及格** = 成绩 ≥ 满分 × 60%（可调）
- **优秀** = 成绩 ≥ 满分 × 80%（可调）
- **班级结构总分** = 人均得分 + 合格率得分 + 优秀率得分 + 进线率得分 + 参考率得分 + 前N名得分 + 增值评价
- **教师考核分** = 平均分得分 + 及格率得分 + 优秀率得分

详细公式见系统内"算法参数"页面的"算法说明"。

## 激活码系统

系统采用「机器绑定 + 激活码」保护机制：
- 每台电脑有唯一的**机器码**（基于硬件信息生成）
- 管理员根据机器码生成对应的**激活码**
- 用户输入激活码后即可正常使用，激活一次永久有效

### 管理员工具

打包管理员工具：

```bash
python -m PyInstaller admin_genkey.spec --noconfirm
```

生成激活码：

```bash
激活码生成工具.exe <学校代码> <机器码>
```

详细说明见 `激活码使用说明.md`。

## 注意事项

- `config/` 目录存放教师任课等配置，请勿删除
- `uploads/` 为临时目录，可随时清空
- 修改算法参数后会影响所有年级的计算结果
- Excel 表头中"班级"列之后、"总分"列之前的所有列会被识别为科目
